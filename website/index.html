01 / ПОВСЕДНЕВНАЯ РУТИНА

Вместо четырёх вкладок — один взгляд.

Вручную в браузере
  1. Открыть «Академикс», снова выбрать отделение и учебную группу.
  2. Найти ссылку на Google Таблицу консультаций на сайте колледжа.
  3. Переключиться на нужный лист недели и вручную искать фамилии своих преподавателей среди сотни строк.
  4. Сверять столбцы с датами в самом верху таблицы и отслеживать изменения самостоятельно.
В URTK Flow
  • Группа выбирается один раз — список ваших преподавателей подтягивается автоматически.
  • Парсер сам открывает актуальный лист недели и скрывает уже прошедшие даты и часы.
  • Утренний пуш в Windows предупреждает, если у нужного преподавателя появилась консультация.
  • Расписание и консультации всегда видны прямо на обоях рабочего стола, даже без интернета.
02 / ВОЗМОЖНОСТИ

Спроектировано под ритм колледжа.

Никаких лишних экранов. Только те данные, которые действительно нужны каждый день.

Умный парсер консультаций

Автоматически находит актуальный недельный лист в Google Таблице, отсекает прошедшие даты и сопоставляет сокращённые ФИО из «Академикса» с полными именами преподавателей.

Все 78 групп УРТК

Расписание любой группы напрямую из JSON API «Академикса», автопереход на новую неделю в выходные, встроенные звонки и быстрый доступ к папкам ДО и Moodle.

Виджет рабочего стола

Модульная стеклянная карточка на обоях: прибивается к уровню рабочего стола через Win32 API, запоминает позицию и не сворачивается при нажатии Win+D.

Настраиваемые уведомления

Нативные пуши Windows при появлении новой консультации или изменении расписания, утренняя сводка в выбранное время — любой триггер включается в один клик.

Ядро на Rust и офлайн-кэш

Никакого тяжёлого Electron: нативный движок на Rust + Tauri v2, локальная база SQLite и мгновенный старт. Приложение работает даже без подключения к сети.

Оптический Liquid Glass

Нативное размытие Windows 11 Acrylic, ровные системные скругления без рамок и переключение между тёмным и светлым стеклом прямо в заголовке окна.
